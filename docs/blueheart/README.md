## Resumen del proyecto

BlueHeart nace con el propósito de aumentar las probabilidades de que dos personas compatibles construyan una relación sana, estable y satisfactoria, utilizando la inteligencia artificial para comprender a las personas —sus valores, necesidades, objetivos de vida y forma de comunicarse— antes de recomendar que se conozcan.

> "BlueHeart no busca encontrar la pareja perfecta; busca evitar las parejas claramente incompatibles."

El proyecto se apoya en dos sistemas complementarios:

- **El algoritmo**, que aplica las reglas, pesos y criterios de compatibilidad del método.
- **La inteligencia artificial**, que conversa con el usuario, interpreta sus respuestas, construye su Perfil de Compatibilidad y explica los resultados del algoritmo.

La decisión final sobre iniciar, mantener o finalizar una relación pertenece siempre a las personas. BlueHeart ofrece información; nunca decide por ellas.
